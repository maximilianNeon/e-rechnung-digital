# E-RechnungDigital

Statische Website und Browser-Werkzeug für XRechnung und ZUGFeRD unter https://erechnungdigital.com. Rechnungsdaten bleiben im Browser. Download ist der einzige Ausgang.

## Entwicklung

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Hinweis

Impressum, Datenschutz und Nutzung enthalten Platzhalter in eckigen Klammern. Vor dem Onlinegang eigene Angaben einsetzen und rechtlich prüfen lassen.
